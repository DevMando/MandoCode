# MandoCode CLI 0.16.1 release preparation

Prepared October 21, 2026. This is a CLI patch release; Desktop versioning and RazorConsole.Core 0.6.0 are unchanged. No tag, GitHub release, or NuGet publication has been created.

## Release summary

The chat input loop now waits for model validation and MCP initialization to finish, including when startup status updates trigger another render. Prompt state changes run together on the UI dispatcher. Closing an agent during the startup delay prevents its input loop from starting afterward.

This release also includes the clipboard fixes, component lifecycle refactoring, and test infrastructure improvements listed in the [changelog](../CHANGELOG.md#0161---2026-10-21).

The startup race is covered by a regression that fails with the previous gate. The exact intermittent repeated-border screen has not been reproduced automatically; successful interactive retesting is encouraging but does not establish that every rendering failure is resolved.

## Completed validation

- Release builds and complete test suites on Windows: 1,247 passing tests on net8.0 and 1,247 on net10.0.
- Startup lifecycle checks: 25 fresh test processes per framework, three tests per process, all passing.
- Broader component checks: three fresh test processes per framework, 234 tests per process, all passing.
- Local `MandoCode.0.16.1.nupkg` created and checked for version 0.16.1 and both runtime payloads.
- Package installed as a .NET tool into an isolated directory using only the local package source. The installed executable's `--doctor` command passed against the available local Ollama server.
- Whitespace validation passed. Local debugging settings are excluded from the release changes.

Local artifacts are under `artifacts/packages/`, `artifacts/release-validation/`, `artifacts/startup-stability/`, and `artifacts/component-stability/`. These ignored files are not committed.

## Remaining release checks

- Run the existing GitHub Actions matrix on Windows and Linux for both frameworks after pushing the release branch. Local Windows results do not establish Linux compatibility.
- Complete the [interactive terminal checklist](../testing.md#interactive-terminal-smoke-checklist), including 10–20 launches each from Visual Studio and Windows Terminal. Type immediately, use Alt+N/Alt+W, resize, and exercise model selection with slow/unavailable Ollama and MCP startup. Record the terminal, framework, model, and outcome.
- Review and merge the release changes, then create the v0.16.1 tag/release and publish the package as a separate release action.

To retest the isolated installed package from the repository root:

```powershell
./artifacts/tool-smoke/v0.16.1/mandocode.exe
```

Repeatable startup and component commands are documented in [testing.md](../testing.md#stability-and-targeted-mutation-checks).
